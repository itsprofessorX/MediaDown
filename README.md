## ✨ Features

| Feature | Description |
|:---|:---|
| 📸 Photos | Download Instagram photos |
| 🎬 Videos | Save Instagram videos |
| 🎞️ Reels | Download Instagram Reels |
| 🖼️ Carousel | Support for multiple-media posts |
| 🔐 Instagram Login | Authentication support |
| 🍪 Cookie Import | Import Instagram cookies |
| ⚡ Quick Share | Download directly through Android Share |
| 🎵 MP3 Audio | Extract audio in MP3 format |
| 📥 Download History | Access previous downloads |
| 📊 Progress Tracking | Monitor download progress |

## 🚀 Installation

1. Visit the [Releases](https://github.com/itsprofessorX/MediaDown/releases) page.
2. Download the latest APK.
3. Install it on your Android device.
4. Open MediaDown and paste an Instagram link.
5. Start downloading!

## 💻 Build From Source

Clone the repository:

```bash
git clone https://github.com/itsprofessorX/MediaDown.git
```

Open the project in Android Studio.

Build the APK:

```bash
./gradlew assembleDebug
```

Find the generated APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```
